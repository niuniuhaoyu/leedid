# leedid design

User authorization: implement candidate 3 fully, validate, document in English and Chinese, and push to user's GitHub. Other candidates are recorded in the separate research roadmap. Execution is inline.

Build a standalone Stata 16+ ado/Mata package, named leedid, for Viviens (2026), arXiv:2502.08614v2 (original 2025 title: Difference-in-Differences and Changes-in-Changes with Sample Selection). Methodological authorship remains Javier Viviens. Stata implementation: Haoyu Niu.

Scope: two-period panel with full unit roster, binary fixed treatment assignment, one or more selection sources, declared source-specific monotonicity signs, and absorbing source-specific missingness. Multiple causes must be mutually exclusive. Preserve baseline nonselection in the selection denominator. Require outcome data where selected; ignore outcomes where unselected. Do not claim staggered treatment, covariate adjustment, arbitrary re-entry or discrete-outcome identification.

API: leedid outcome [if] [in], unit(id) time(t) treat(g) selection(s1 ...) directions(1 -1 ...) [pre(#) post(#) probs(numlist) reps(#) seed(#) level(#) cluster(varname) graph]. Both periods inferred only for exactly two distinct periods; otherwise both required. reps defaults 199, 0 skips inference. Quantile grid defaults .1(.1).9. Directions are substantive assumptions, never inferred from observed signs.

Results: both DiD and CiC average bounds, CiC quantile bounds, complete-case comparison estimates, AO shares, selection diagnostics, bootstrap covariance and Imbens–Manski pointwise parameter CIs. No p-values for the bound endpoints. e(sample) includes the full selected roster, including units without observed outcomes. Display the complete-case estimation counts separately.

Computation: empirical inverse CDF (type 1); exact fractional-mass DiD trimming; exact integration of empirical CiC bounds using their quantile breakpoints (independent of display grid). These improve on rounded trimming and coarse-grid averaging in the R reference; document differences and compare matching building blocks. Probability clipping to [0,1] must be diagnosed. Nonpositive AO proportions are unidentified and error. Bootstrap at unit level, or whole user clusters; re-estimate shares every draw. If a draw is undefined, report failed count and withhold all bootstrap inference (no silent successful-draw conditioning).

Tests: hand-calculated bounds; point-identification reduction; baseline nonselection; positive/negative/multiple sources; ties and noninteger retained mass; exact integral; grid invariance; row order; missing/duplicate IDs, changing treatment, inconsistent selection, re-entry, incomplete panels; reproducible unit and cluster bootstrap; R building-block parity and shared-resample inference parity; end-to-end net install and plotting. Use installed Stata MP and R. Record evidence and limitations before publication.
