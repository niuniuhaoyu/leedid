# leedid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver and publish a tested native Stata implementation of Viviens DID/CiC selection bounds.
**Architecture:** Stata validation and results wrapper, pure Mata estimation kernel, Mata bootstrap with re-estimated selection shares, Stata plotting command. R/Python references remain tests only.
**Tech Stack:** Stata 16+ ado/Mata; R and Python 3 for verification.
**Spec:** docs/superpowers/specs/2026-10-15-leedid.md

## Global Constraints
- Full roster retained; declared monotonicity signs; no arbitrary re-entry.
- No dependencies for users; methodological attribution to Viviens.
- Exact empirical CiC integration independent of reporting grid.
- Invalid bootstrap draws suppress inference and are reported.

## Review Focus
- Outcome missingness must not change AO-share denominators.
- Display quantile grid must not change average bounds.
- Cluster resampling must keep all member units together.
- Probability boundary failures must be visible, never silently discarded.
- Empirical mass at a trimming threshold must receive fractional weights.
